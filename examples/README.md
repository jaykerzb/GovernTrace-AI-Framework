# Worked Examples

Fully filled-out example use cases, so you can see the framework applied to a realistic scenario instead of staring at blank templates. Fictional company, fictional vendor, fictional data — but the reasoning (why this risk tier, why this control) is written to reflect how a real governance review should go.

## Available examples

| Example | Sector | Demonstrates |
|---|---|---|
| [Loan Pre-Qualification Chatbot](loan-prequalification-chatbot/README.md) | Banking | High-risk classification, fair lending review, the [Banking sector pack](../sectors/banking-financial-services/README.md) in use, human-in-the-loop design under regulatory pressure |

## How to use these

Read the scenario `README.md` first for context, then walk the numbered files in order — they mirror the actual sequence a use case moves through: intake → risk assessment → vendor due diligence → model card → bias/fairness testing → pre-deployment checklist. Each file is a completed version of the corresponding blank template in [`templates/`](../templates/).

These are teaching examples, not legal templates to copy verbatim — the specific conclusions (risk tier, mitigations, sign-offs) are illustrative of the *reasoning process*, not a substitute for your own organization's actual review.
